# BuildSphere Frontend

React + Vite + TypeScript frontend for BuildSphere.

## MVP responsibilities

- Authentication screens.
- Dashboard.
- Project wizard.
- Project detail pages.
- Pipeline timeline.
- Log viewer.
- Suggestions UI.
- Generated file viewer and TAR download.
- Deployment target and manifest validation views.
- Platform health and notifications.

## Commands

```bash
pnpm dev
pnpm build
pnpm test
```

The frontend reads `VITE_API_URL` and defaults to `http://localhost:8080/api`.
