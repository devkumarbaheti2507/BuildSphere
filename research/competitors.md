# Competitor Notes

## GitHub Actions

Strengths:

- Native to GitHub.
- Huge marketplace.
- Easy YAML workflows.

BuildSphere opportunity:

- Explain workflows visually.
- Generate workflows from guided choices.
- Connect workflows to project architecture.

## Jenkins

Strengths:

- Flexible.
- Widely used in enterprises.

BuildSphere opportunity:

- Reduce setup complexity.
- Generate Jenkinsfiles from templates.

## GitLab CI/CD

Strengths:

- Integrated with GitLab.
- Strong DevOps lifecycle features.

BuildSphere opportunity:

- Multi-tool, learning-focused, template-driven experience.

## Backstage

Strengths:

- Internal developer portal concept.
- Software catalog.

BuildSphere opportunity:

- More beginner-friendly.
- Stronger CI/CD and DevOps explanation focus in MVP.
