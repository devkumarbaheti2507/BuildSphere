# ADR-002-Architecture: Microservice-Oriented Architecture

## Status

Accepted

## Context

The product itself should demonstrate microservice, DevOps, and platform engineering concepts.

## Decision

Use a microservice-oriented architecture for backend services, while allowing simple local development.

## Alternatives considered

- Build everything in one app.
- Use external managed services from day one.
- Delay documentation until after implementation.

## Consequences

Positive:

- Clear source of truth.
- Easier onboarding.
- Strong portfolio value.
- Easier AI-assisted development.

Tradeoffs:

- More initial structure.
- Requires discipline to keep docs updated.
